# Aegis invocation supplement

The existing invocation and skill are canonical for mode boundaries and ten-domain coverage. Before Review, Harden or Triage, record target and immutable ref, date, owner/decider, authorization reference, scope, exclusions, depth, budget and contact when applicable. Missing authorization is not permission. Active testing defaults to no. Review changes nothing; Harden never merges; Triage only performs explicitly approved containment.

Default advisory source for this repository: GitHub Advisories; cadence: weekly (version updates), immediate security updates when enabled. Record the actual advisory check date and outcome, not the invocation date. Optional advisory source overrides must be reconciled with the target's SECURITY.md.

Use redaction for all modes; no full secrets even when redaction is set to none. A one-liner cannot substitute for missing authorization or evidence. Use the AEGIS REPORT contract.
